TRIVEX HARNESS AUDITOR v2.8 - PORTABLE WINDOWS BUILD

1. Extract this ZIP to a normal folder on the Windows PC.
2. Verify the SHA-256 value in SHA256.txt if your organization requires it.
3. Run Trivex_Harness_Auditor_v2.8.exe.

The executable is portable and keeps drawing processing on the local PC. It does
not upload source PDFs. Windows may display a publisher warning because this build
is not yet Authenticode-signed.

LABOR REFERENCE LIBRARY
The automatic labor-reference store belongs to one Windows/browser profile. To
move it to another PC, choose "Save reference library file" on the first PC and
"Load reference library" on the second. Keep that JSON under the same controls as
your estimating data. Source PDFs are not embedded in the reference library.

SOURCE AND UPDATES
Repository: https://github.com/jbaker471-hue/harness_reader
